# -sei-plus-aprendizado
Este repositório é o diário técnico de um projeto em desenvolvimento estudados no livro, o código produzido a partir da leitura e a decisão de projeto que aquela leitura permitiu tomar. O objetivo não é resumir a obra, e sim demonstrar, de forma verificável, como a base de Padrões Web sustenta uma ferramenta de gestão processual construída do zero.
