# SEI Plus — Repositório de aprendizagem

Registro técnico do percurso de estudo de Fundamentos de HTML5 e CSS3 (Maujor, 2015) aplicado à construção da ferramenta SEI Plus.

## Sobre este repositório

Este repositório é o diário técnico de um projeto em desenvolvimento. Cada arquivo de capítulo registra o que foi estudado no livro, o código produzido a partir da leitura e a decisão de projeto que aquela leitura permitiu tomar. O objetivo não é resumir a obra, e sim demonstrar, de forma verificável, como a base de Padrões Web sustenta uma ferramenta de gestão processual construída do zero.

> **Estado atual:** Somente o relato do capítulo 1 está publicado. Os capítulos seguintes estão previstos e serão adicionados conforme o estudo avançar.

## A ferramenta que este estudo constrói

Ferramenta web de modelagem visual de fluxos processuais e de organização de modelos de documentos, destinada a equipes administrativas que precisam descrever e padronizar o caminho de um processo sem depender de sistemas corporativos contratados.

*   **Modelagem visual de fluxos:** Representação do caminho de um processo em etapas encadeadas, com setor responsável e ponto de decisão, editável no próprio navegador.
*   **Modelos de documentos:** Biblioteca de minutas padronizadas — ofícios, pareceres, despachos — prontas para copiar e reutilizar, reduzindo retrabalho de redação.
*   **Soberania digital:** Código próprio em HTML5, CSS3 e JavaScript puro, armazenamento local no navegador e publicação estática: nenhum dado processual sai da máquina do usuário.

## Relação com o edital

O SEI Plus é apresentado como solução de baixo custo de implantação para a gestão de fluxos e documentos em unidades administrativas. A ferramenta proposta ao edital é construída inteiramente sobre Padrões Web abertos, o que elimina licenças de software, servidores dedicados e dependência de fornecedor único.

Este repositório existe para dar transparência a essa proposta: o histórico de aprendizagem documenta a capacidade técnica de construir e manter a ferramenta, capítulo por capítulo, com o código correspondente versionado e auditável. Os requisitos específicos do edital serão detalhados em documento próprio, à medida que forem consolidados.

Entregáveis previstos:

*   Interface web do modelador de fluxos, executada no navegador.
*   Biblioteca de modelos de documentos com cópia para a área de transferência.
*   Persistência local dos fluxos, sem envio de dados a serviços de terceiros.
*   Publicação estática, reproduzível e de baixo custo de manutenção.
